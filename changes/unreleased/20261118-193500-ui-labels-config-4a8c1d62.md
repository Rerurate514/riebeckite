UI strings are now localizable through configuration. `ui.locale` pins the UI language independently of the content language, and `ui.labels` supplies language-specific overrides for the built-in interface strings — the table of contents heading and label, the sidebar filter box, the search bar, series navigation, nearby notes, the language switcher, and collapse/expand announcements. Plugins resolve them through the new `useUiLabels()` hook, sites can extend the dictionary with their own keys, and sites without `ui` settings render exactly the same English strings as before.
