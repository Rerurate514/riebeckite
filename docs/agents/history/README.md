# Historical Records

This directory preserves records that no longer describe current behavior but remain useful when tracing past decisions. Nothing here is part of the published site or the active maintenance workflow.

|Directory|Contents|Original location|
|---|---|---|
|`benchmarks/`|Incremental build and CI investigation reports|`benchmarks/reports/`|
|`slides/`|Project overview slide deck (HTML and PDF)|`slides/`|
|`notes/`|Personal image notes and an empty backlog table|repository root|
|`architecture/`|Asset pipeline phase 2-3 verification report|`docs/architecture/`|

Treat every file as read-only context. Do not update it to match new behavior; add a new report instead.
