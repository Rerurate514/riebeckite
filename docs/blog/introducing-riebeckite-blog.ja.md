Riebeckite 公式サイトに、このブログを追加しました。これまでサイトは[ドキュメント](/docs/)で使い方を説明する場でしたが、プロジェクトの周りの話——なぜその設計判断をしたのか、リリースの間に何が変わったのか、Riebeckite を使った人が何を作っているのか——を置く場所がありませんでした。

## 何を書くか

記事は次のカテゴリで増やしていきます。

- **Updates** — リリース情報や開発のニュース。この記事もその一つです。
- **Engineering** — Riebeckite 自体の作りに関する技術ノート。[このブログそのものの構成](/blog/how-this-blog-is-built/)は、フレームワークの既存部品だけを組み合わせて作っています。
- **Comparisons** — 他の静的サイトジェネレーターや公開ツールとの、実際に使ってみてからの比較。
- **Tutorials** — Obsidian の vault を Web サイトにする、といった実践的な手順。[ドキュメント](/docs/getting-started/)を置き換えるものではなく、補うものです。

使い方の正しい情報源は、引き続きドキュメントです。ブログはその周りの文脈——経験や意見、ニュース——を足す場所で、設定の詳細に踏み込む記事は該当するドキュメントへのリンクで済ませます。

## 英語と日本語の両方で

Riebeckite のサイトは英語と日本語で公開しており、ブログも同じです。翻訳がある記事には言語スイッチャーが表示され、まだの記事については用意できるものから順に追加します。

## 購読方法

更新の確認はフィードでできます。

- [RSS](/feed.xml)
- [Atom](/atom.xml)

記事にはタグが付くので、[announcements](/tags/announcements/) のように、関心のある話題だけを追うこともできます。

次の記事はすでに用意しています。読んでみたい話題があれば、[GitHub](https://github.com/Rerurate514/riebeckite) で issue を開いてください。
