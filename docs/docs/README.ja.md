# ドキュメント

Riebeckite は Obsidian Vault（または任意の Markdown フォルダ）を静的サイトに変換します。[クイックスタート](./getting-started/quick-start.ja.md) から始めてサイトを作成・公開するか、以下のタスク表から目的のページへ移動してください。
