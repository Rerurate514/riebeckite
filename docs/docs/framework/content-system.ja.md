# コンテンツシステム

コンテンツシステムは、Markdown や画像などのファイルを、Riebeckite がサイトとして扱えるコンテンツへ変換する仕組みです。

Markdown を HTML に変換するだけではありません。Riebeckite は次の問いに答える必要があります。

- このファイルは何の記事か
- 公開してよいか
- どの URL で公開するか
- 他の記事とどうつながっているか
- [[glossary/plugin|プラグイン]]が何を追加・変更したか

コンテンツシステムはこれらの問いを解決し、サイト全体で同じ情報を利用できる状態にします。
