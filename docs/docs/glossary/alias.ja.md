# Alias

ノートの別名で、manifest に追加の検索キーとして記録します。slug や permalink を変えずに WikiLink を同じノートへ解決しますが、同じ名前を二重に使うと曖昧になります。

## 役割

- ノートに追加の検索キーを与えます。
- ノートと同じ slug と permalink に解決します。
