# Attachment

content ツリー内でコンテンツ entry ではなく asset として配信されるファイルです。Attachment は論理パスを保ったまま公開 URL に対応し、何を公開して安全かは publication boundary が決めます。

## 役割

- コンテンツから参照される Markdown 以外のファイルを配信します。
- 論理パスを公開 URL に対応させます。
