# ブロックID（Block ID）

段落やブロックに付ける短い識別子で、見出しなしでそのブロックを直接リンクしたり埋め込んだりできるようにします。

## 記法

```md
この段落を参照できます。 ^intro

![[note#^intro]] で埋め込めます。
```

## 用途

ブロック ID を使うと、埋め込みや WikiLink がノート全体やセクションではなく、1つのブロックを対象にできます。

## ブロックIDの解決

`^intro` のようなブロック ID は、埋め込みと WikiLink の処理中にコンテンツインデックスが解決します。ID はソースノート内のブロックのアンカーと照合され、解決されたパスは埋め込みなら `![[note#^intro]]`、WikiLink なら `[[note#^intro]]` の形に従います。

## ブロックIDとコンテンツ依存関係

ブロック ID を埋め込み（`![[note#^intro]]`）で使うと、埋め込む側のページはソースノートのコンテンツ依存関係になります。ソースノートのブロックを編集すると埋め込みページが無効化される点は、ノート単位の埋め込みの追跡と同じです。
