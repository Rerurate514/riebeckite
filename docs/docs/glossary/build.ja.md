# Build

コンテンツを処理し、公開位置を解決し、Plugin を実行し、manifest と graph を作り、出力を書き出す Riebeckite の処理です。サイトが配信するファイルを生成する、ビルド時の Node.js の操作です。

## 役割

- コンテンツと設定を出力ファイルに変えます。
- manifest と生成物を生み出します。
