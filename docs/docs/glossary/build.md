# Build

The Riebeckite process that processes content, resolves locations, runs plugins, builds the manifest and graph, and writes the output. It is a build-time Node.js operation that produces the files the site serves.

## Role

- Turns content and configuration into output files.
- Produces the manifest and generated outputs.
