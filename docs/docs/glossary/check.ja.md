# Check

Plugin依存の循環やpermalinkの重複など、Buildを壊す問題がないか、サイトの設定とコンテンツを検証するCLIコマンドです。

## 検証する内容

Pluginの依存関係の循環、提供capabilityの重複、permalinkの衝突、公開設定の誤りなどを調べます。Buildの前に実行し、失敗につながる問題を早く見つけます。
