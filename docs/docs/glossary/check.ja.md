# Check

Plugin 依存の循環や permalink の重複など、Build を壊す問題がないか、サイトの設定とコンテンツを検証する CLI コマンドです。

## 役割

- Build の前に設定とコンテンツを検証します。
- Build を失敗させる問題を報告します。
