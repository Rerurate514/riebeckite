# Check

 Build 前に config、 plugins、 capabilities が正しく設定されているか検証する CLI コマンドです。

## 検証内容

 config format が有効か。
 Plugin の設定 が有効か。
 必要な capability が成立しているか。

## 目的

 出力がビルドされてDeploy されていることを保証するものではない。
 Configuration が有効であることを保証する。
