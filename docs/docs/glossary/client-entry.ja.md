# Client Entry

Plugin がクライアント側の挙動のために登録するブラウザの入口です。Client entry はフレームワークに依存せず、HonoX や特定の UI フレームワークに縛られません。

## 役割

- Plugin の機能にブラウザ側のコードを加えます。
- Integration のフレームワークから独立しています。
