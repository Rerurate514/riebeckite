# Config

コンテンツ、公開、Plugin、Theme、cache の挙動を制御する Riebeckite の設定オブジェクトです。Build が使う前に検証し、解決します。

## 役割

- サイトをどう Build し公開するかを宣言します。
- 使用前に検証し、解決します。
