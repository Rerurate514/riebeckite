# Content Entry

manifest の中で slug により識別される、解決済みのコンテンツ 1 件です。permalink、公開位置、frontmatter、公開状態、HTML、Plugin が付与したデータを持ちます。

## 役割

- ページや Plugin が参照する 1 ノート分のレコードです。
- 内部の slug と解決済みの公開位置の両方を持ちます。
