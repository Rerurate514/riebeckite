# Content Graph

解決済みの WikiLink と Markdown リンクから作られる、コンテンツ entry 間の関係の網です。どのノートがどれを参照しているかを答え、backlink や近傍の問い合わせに使います。

## 役割

- entry 間の outgoing、incoming、neighbor の関係を持ちます。
- Plugin が独自の関係を追加して拡張できます。
