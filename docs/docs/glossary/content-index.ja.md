# Content Index

WikiLink や embed を解決するための、小文字化した名前からノートへの対応表です。複数のノートに一致する名前は載せず、誤った解決を避けて diagnostic として報告します。

## 役割

- WikiLink の対象を basename、パスの後方一致、alias で解決します。
- 曖昧な名前は対応表から外し、diagnostic で知らせます。
