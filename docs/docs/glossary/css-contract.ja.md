# CSS Contract

コンポーネントが依存してよい、data 属性などの安定した CSS hook です。Theme はこの hook を守ることで、コンポーネントが特定の Theme を前提にせず装飾できます。

## 役割

- コンポーネントが依存できる styling hook を定めます。
- コンポーネントを特定の Theme から独立させます。
