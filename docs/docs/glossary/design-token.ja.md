# Design Token

色や余白といった値を CSS カスタムプロパティとして公開する名前付きの値です。Token はカスケードと data 属性を通り、コンポーネントと Theme が安定した語彙を共有できるようにします。

## 役割

- 色や余白などの再利用する設計値を名付けます。
- CSS カスタムプロパティとして公開します。
