# Design Token

A named value such as a color or spacing exposed as a CSS custom property. Tokens flow through the cascade and data attributes so components and themes can share a stable vocabulary.

## Role

- Names reusable design values such as colors and spacing.
- Exposes them as CSS custom properties.
