# Diagnostic Code

diagnostic に付く安定した識別子で、ツールが問題を絞り込み、まとめ、表示するために使います。コードがあれば、メッセージの文面に頼らず特定の問題を照合できます。

## 役割

- diagnostic の種類を識別します。
- メッセージを解析せずに問題を照合できます。
