# Diagnostics

コンテンツ処理中に集める警告とエラーで、manifest にまとめ、plugin runtime から読み出します。コンテンツを黙って落とす代わりに、回復可能な問題を報告します。

## 役割

- コンテンツと設定の回復可能な問題を報告します。
- manifest にまとめ、ツールが表示します。
