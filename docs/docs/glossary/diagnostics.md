# Diagnostics

Warnings and errors collected while content is processed, gathered in the manifest and read through the plugin runtime. They report recoverable problems instead of silently dropping content.

## Role

- Reports recoverable content and configuration problems.
- Are collected in the manifest and surfaced by tools.
