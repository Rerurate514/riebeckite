# Discoverable

一覧、feed、ナビゲーションに載せてよい entry を示す公開ビューです。routable でも unlisted のページは URL では提供しつつ、このビューには含めません。

## 役割

- 一覧、feed、discovery 系の widget に供給します。
- routable でも unlisted の entry を除外します。
