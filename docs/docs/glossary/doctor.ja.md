# Doctor

サイトの構成と環境を確認し、Integration、Theme、デプロイ先が整っているかを検証するCLIコマンドです。Checkよりも周囲の構成について多くを報告します。

## 確認する内容

環境とサイトの構成を確認します。Integration、Theme、デプロイの準備状況を検証します。
