# Doctor

サイトの構成と環境を確認し、Integration、Theme、デプロイ先が整っているかを検証する CLI コマンドです。check よりも周囲の構成について多くを報告します。

## 役割

- 環境とサイトの構成を確認します。
- Integration、Theme、デプロイの準備状況を検証します。
