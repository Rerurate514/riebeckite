# Draft

公開の判定によって公開サイトから外されるコンテンツです。処理自体は続けられますが、公開されるまで routable と discoverable のビューから除外されます。

## 役割

- まだ公開できないコンテンツを表します。
- 公開されるまでルーティングと一覧から外れます。
