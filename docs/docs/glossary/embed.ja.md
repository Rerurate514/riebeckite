# Embed

別のノートの内容を現在のページに取り込む記法で、ノートの埋め込みや block の埋め込みがあります。リンクと同様に解決し、content dependency として追跡します。

## 役割

- 別のノートの内容を現在のページで再利用します。
- 依存として数え、変更を伝播させます。
