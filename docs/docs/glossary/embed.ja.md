# 埋め込み（Embed）

別のノートの内容を現在のページに取り込む記法で、ノートの埋め込みやブロックの埋め込みがあります。埋め込みはリンクと同じように解決され、コンテンツ依存関係として追跡されます。

## 記法

```md
![[note]]            # embed a whole note
![[note#Heading]]    # embed a section
![[note#^block-id]]  # embed a block
```

## 解決と依存関係

埋め込みはWikiLinkと同じくコンテンツインデックスを通じて解決され、コンテンツ依存関係になります。参照元のノートを編集すると、それを埋め込むページが無効化されます。

## コンテンツ依存関係の追跡

埋め込みはコンテンツインデックスを通じてコンテンツ依存関係として追跡されます。ほかのページに埋め込まれているノートを編集すると、システムはそれらのページを無効化し、次のビルドで再生成します。WikiLinkがグラフの辺を作るのと似ていますが、埋め込みには依存するページを再ビルドの対象として印を付ける働きが加わります。

詳しくは用語集の[[content-dependency|content-dependency]]で説明しています。
