# Endpoint

Plugin がブラウザや外部サービスへ公開する route です。Integration は Plugin の endpoint を汎用の route に通して解決し、Application が文書の枠組みを保ちます。

## 役割

- Plugin が実行時の応答を返せるようにします。
- Integration の route を通して解決し、Plugin が所有はしません。
