# Feed

公開されたコンテンツを機械可読に並べたもので、RSS、Atom、JSON Feed などがあります。Feed は discoverable な entry から作り、各 entry の permalink を使います。

## 役割

- 最近のコンテンツを読者やツールへ配信します。
- discoverable な entry と permalink を使います。
