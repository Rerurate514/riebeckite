# Feed

A machine-readable list of published content, such as RSS, Atom, or JSON Feed. Feeds draw from the discoverable entries and use each entry's permalink.

## What feeds use

- The [discoverable](./discoverable.md) entries, so unlisted pages stay out.
- Each entry's [permalink](./permalink.md), never a URL rebuilt from the slug.
- Title, date, and description from frontmatter.

## Feed generation
Feeds are generated by the SEO plugin (`packages/plugins/seo/src/feeds.ts`) using the resolved config and filtered entries. The three formats are:

| Format | Typical use |
| --- | --- |
| RSS | Widest reader support |
| Atom | Stricter, well-defined |
| JSON Feed | Feeds for programmatic use |

Feed entries are drawn from discoverable entries (so unlisted pages are excluded), and each entry's permalink is used (not a URL rebuilt from the slug). Feed metadata (title, description, language) comes from `config.site.feed`. The number of entries is limited by the `feed.limit` option.

```ts
import { renderRssFeed, renderAtomFeed, renderJsonFeed } from "@riebeckite/plugin-seo";
```

The `getResolvedFeedMetadata` function extracts `title`, `description`, and `language` from `config.site.feed`. Feed generation uses `filterFeedEntries` to exclude entries with `noindex: true` and sorts by publication date.
