# Feed

A machine-readable list of published content, such as RSS, Atom, or JSON Feed. Feeds draw from the discoverable entries and use each entry's permalink.

## What feeds use

- The [discoverable](./discoverable.md) entries, so unlisted pages stay out.
- Each entry's [permalink](./permalink.md), never a URL rebuilt from the slug.
- Title, date, and description from frontmatter.

## Feed generation
Feeds are generated by the SEO plugin (`packages/plugins/seo/src/feeds.ts`, wired in `endpoints.ts`). Feed generation uses `filterFeedEntries` in `seo/src/content.ts` to exclude entries marked `noindex: true` and sorts by publication date.

```ts
import { renderRssFeed, renderAtomFeed, renderJsonFeed } from "@riebeckite/plugin-seo";
```

The `getResolvedFeedMetadata` function in `feeds.ts` extracts `title`, `description`, and `language` from `config.site.feed`; the `feed.limit` option caps the entry count. The three formats:

| Format | Typical use |
| --- | --- |
| RSS | Widest reader support |
| Atom | Stricter, well-defined |
| JSON Feed | Feeds for programmatic use |

## Localized sites

Feeds are not split by language. A site with localized content publishes one feed per format whose `<language>` comes from `config.site.feed.language` (or `site.locale`), and the entry list contains every locale's discoverable entries together — for example, English and Japanese posts interleaved. Readers that filter by language should detect the locale from each item's permalink; raise `feed.limit` so recent posts in every language make the cut.
