# Fingerprint

コンテンツやファイルの入力を識別し、変化を検出できるようにするハッシュです。保存した値と異なれば、依存するコンテンツを再処理します。

## 役割

- 入力が変化したかを検出します。
- cache と build state の比較を駆動します。
