# Folder Page

単一のファイルではなくフォルダを代表するページで、folder-pages Plugin が扱います。ディレクトリに entry と公開 URL を与えつつ、配下のページはそれぞれのパスを保ちます。

## 役割

- フォルダ自身にページを与えます。
- 配下のページはフォルダの下で参照可能に保ちます。
