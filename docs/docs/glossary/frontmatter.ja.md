# Frontmatter

コンテンツファイルの先頭にある YAML のブロックで、title、date、tags、visibility などの型付きメタデータに解析されます。slug とは独立にノートを識別する安定した id もここに置きます。

## 役割

- ノートの構造化メタデータを供給します。
- published、visibility、tags、series などの field を設定します。
