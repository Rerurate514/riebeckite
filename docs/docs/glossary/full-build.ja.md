# フルビルド（Full Build）

以前の増分ビルドの状態を再利用せず、すべてのコンテンツを最初から処理するビルドです。

## 使う場面

`--full`は、ビルドを再現したいときや、増分ビルドの挙動の問題を切り分けたいときに使います。
ビルド時間の比較や、増分ビルドの結果が疑わしいときに役立ちます。

## コマンド

`riebeckite build --full`
または
`pnpm exec riebeckite build --full`

## `--full`が選ばれる条件

次の場合、`--full`は自動的に選ばれます。
- 前回のビルド状態がない（初回のビルド）
- 前回のビルド状態のバージョンが現在のバージョンと互換性がない
- パイプラインのフィンガープリントが変わり、以前の状態を安全に再利用できない
- キャッシュスキーマのバージョン不一致により、有効なキャッシュエントリを参照できない
- 外部依存関係の失敗により、増分処理を進められない

`--full`を指定した場合でも、生成されるウェブサイトは同じで正しくあります。違いは、増分ビルドの状態を再利用せず、すべてのコンテンツを最初から処理する点です。ビルド時間の比較や、増分ビルドの挙動の問題の切り分けに役立ちます。
