# Hreflang

あるページの言語違いの URL を検索エンジンに伝える link メタデータです。Riebeckite はノートに存在する翻訳からこれを生成します。

## 役割

- 言語の代替 URL を検索エンジンに宣言します。
- ノートの翻訳から生成します。
