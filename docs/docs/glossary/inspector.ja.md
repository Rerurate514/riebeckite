# Inspector

コンテンツ entry とその解決済みの状態を読み取り専用で示す仕組みで、公開位置、公開状態、content graph、diagnostic を含みます。コンテンツがどう処理され公開されたかの調査に役立ちます。

## 役割

- 調査のため解決済みのコンテンツ状態を示します。
- 公開位置、公開状態、diagnostic を表示します。
