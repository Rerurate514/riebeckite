# アイランド（Island）

アイランドは、サーバー側で描画したコンテンツの中に埋め込む、クライアントでハイドレーションできるコンポーネントです。ページ全体をハイドレーションせずに、対話的なUIの一部分だけを動かせます。アイランドコンポーネントを定義するのはサイトアプリケーションであり、プラグインではありません。

## アイランドパターン

アイランドを使うと、対話的なコンポーネント（ウィジェットやグラフなど）をサーバーで描画し、必要な箇所だけクライアントでハイドレーションできます。JavaScriptのペイロードが減り、操作できるようになるまでの時間が短くなります。

## サイト側の責務

アイランドの配置、ルーティング、ハイドレーションはサイトアプリケーションが担います。プラグインはサーバー描画コンポーネントを公開できますが、アイランドのロジックはアプリケーション層にあります。
