# Island

ページの他の部分を静的なまま、クライアントで hydration される対話的なコンポーネントです。Integration が island を route につなぎ、何を hydration するかは Application が決めます。

## 役割

- 静的なページに対話性を加えます。
- Integration によりクライアントで hydration されます。
