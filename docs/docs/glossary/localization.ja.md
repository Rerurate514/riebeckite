# Localization

1 つのサイトで複数の言語のコンテンツを配信できるようにする l10n Plugin です。ノートの言語を検出し、翻訳をまとめ、言語切り替えを公開します。

## 役割

- 同じサイトを複数言語で配信します。
- 翻訳をまとめ、言語切り替えを提供します。
