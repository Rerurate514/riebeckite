# Manifest

すべてのコンテンツを記録するビルド時の一覧です。entry、公開ビュー、検索用の対応表、content graph、diagnostic を持ちます。ページ生成、実行時の query、incremental build、inspection はいずれも manifest を読みます。

## 役割

- コンテンツ処理からページ生成へ渡す境界です。
- bySlug や byPermalink などの対応表を提供します。
