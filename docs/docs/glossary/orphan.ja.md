# Orphan

どのページからもリンクされていないコンテンツです。診断は既定でオフになっており、有効にすると孤立したentryを報告します。

## 検出

`diagnostics`の設定で孤立したコンテンツの報告を有効にします。一覧やfeedからたどれないページを、Buildを止めずに知らせます。
