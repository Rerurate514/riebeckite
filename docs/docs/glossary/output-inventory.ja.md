# Output Inventory

生成したすべての出力をパスで引けるようにした記録で、公開 entry、redirect、Plugin ページ、生成物から作ります。Build は前回分と比べ、影響する出力、未変更の出力、削除する出力を求めます。

## 役割

- Build が所有する出力を一覧化します。
- どの出力を描画、再利用、削除するかを決めます。
