# Output Inventory

The record of every generated output, keyed by path, built from public entries, redirects, plugin pages, and generated outputs. The build compares it with the previous one to find affected, unchanged, and removed outputs.

## What it contains

Lists all outputs the build owns: content outputs, redirect outputs, plugin-page outputs, and generated outputs. Drives which outputs are rendered, reused, or removed in the current build.

## Output Composition Details

### Content Outputs

Generated from `manifest.publicEntries`. Each content output has:
- `kind`: `"content"`
- `path`: resolved HTML output path (from permalink)
- `producer`: `content:${slug}`
- `dependencies`: `[{ type: "content", slug: "<entry-slug>" }]` plus any output dependencies declared by the plugin

### Redirect Outputs

Generated from `manifest.publicRedirects`. Each redirect output has:
- `kind`: `"redirect"`
- `path`: HTML path for the redirect target
- `producer`: `content:${redirect.slug}:redirect`
- `dependencies`: `[{ type: "content", slug: redirect.slug }]`

### Plugin-Page Outputs

Generated from plugin page definitions (`pageTypes`). Each plugin-page output has:
- `kind`: `"plugin-page"`
- `path`: HTML output path
- `producer`: `plugin:${plugin.name}`
- `dependencies`: declared via `pageTypes[].outputDependencies` or `context.output.emit(..., { dependencies })`

### Generated Outputs

Generated by plugins via `manifest.generatedOutputs`. Each generated output has:
- `kind`: `"generated"`
- `path`: output path
- `producer`: `plugin:${output.owner}`
- `dependencies`: declared via `context.output.emit(..., { dependencies })`; may include `content`, `tag`, `folder`, `global`, or `unknown` types

## Comparison

Compared with the previous successful state to determine affected, unchanged, and removed outputs. The build log reports `SSG outputs` line with `rendered`, `reused`, and `removed` counts.
