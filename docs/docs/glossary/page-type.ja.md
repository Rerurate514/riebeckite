# Page Type

Plugin が独自の公開パスと本文を添えて提供するページの種類で、通常の Markdown ではないページに使います。Integration が route を解決し、Application が最終的な HTML を組み立てます。

## 役割

- Plugin が Markdown 以外のページを提供できるようにします。
- incremental build 用に自身の output dependency を宣言します。
