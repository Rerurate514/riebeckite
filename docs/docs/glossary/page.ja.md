# Page

サイトが URL で提供する、ルーティング可能なコンテンツです。Markdown から作られる場合と、Plugin の page type から作られる場合があり、Integration が route を通して描画します。

## 役割

- URL を持って描画される出力単位です。
- Markdown のコンテンツか、Plugin の page type から生まれます。
