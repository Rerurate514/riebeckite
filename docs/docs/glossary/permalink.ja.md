# Permalink

ノートの公開 URL として解決済みの正準値です。リンク、feed、sitemap、メタデータの唯一の出所であり、slug から再計算せず、公開位置の解決から得ます。

## 役割

- サイト全体で使う正準 URL を提供します。
- slug ではなく解決済みの公開位置から取得します。
