# Preset

よくある構成をまかなうため、configに適用する準備済みのoptionの組です。Presetはよく使うPlugin、Theme、設定をまとめ、わずかな設定で採用できるようにします。

## presetがまとめるもの

- blogやdocsなど用途別のPluginの組。
- 既定のTheme。
- よく使う設定。サイト側は必要な分だけ上書きします。

## 使い方

presetはconfigに展開して使います。サイト自身のoptionを後から適用するため、最終的な設定はサイト側が決めます。
