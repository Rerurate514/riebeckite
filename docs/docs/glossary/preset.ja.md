# Preset

よくある構成をまかなうため、config に適用する準備済みの option の組です。Preset はよく使う Plugin、Theme、設定をまとめ、わずかな設定で採用できるようにします。

## 役割

- 出発点となる用意済みの設定を提供します。
- よく使う Plugin、Theme、option をまとめます。
