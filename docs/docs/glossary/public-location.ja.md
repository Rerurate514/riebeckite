# Public Location

ノートをどこに公開するかを表し、内部の slug と正準の permalink に、任意の redirect とメタデータを組み合わせます。manifest が entry ごとに公開する解決済みの結果です。

## 役割

- slug と permalink、必要に応じて redirect をまとめます。
- Plugin が正準の位置に別名 URL を追加できます。
