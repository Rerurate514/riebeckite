# Publication Boundary

どのコンテンツを公開して安全かを決める規則です。Riebeckite は publish strategy と frontmatter を適用し、公開判定を一箇所に集めます。

## 役割

- 公開するコンテンツを、下書きや除外ファイルから分けます。
- publish strategy と frontmatter を通して適用します。
