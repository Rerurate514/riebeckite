# Redirect

An extra URL that points at a note's canonical permalink, usually to keep an older address working. Redirects are part of the resolved public location and do not replace the permalink.

## When redirects appear

A [permalink](./permalink.md) plugin, a rename, or a locale rule can add a redirect. The note keeps one canonical permalink and any number of redirects. Redirects are part of the resolved public location and do not replace the permalink.

## Redirect type and structure

A redirect is typed as `ContentRedirect` (`packages/core/src/types/content_manifest.ts`) with a `path` and `status` code. It is stored in the manifest's `redirects` map keyed by the redirect path, and also in `publicRedirects` for public entries.

Example `ContentRedirect`:

```ts
{
  path: "/docs/hello/",
  status: 301,
}
```

Example redirects in a manifest entry:

```ts
permalink: "/docs/notes/hello/",
redirects: ["/docs/hello/", "/hello/"],
```

Redirects are generated by permalink plugins through the `resolveContentLocations` hook, or automatically when a content file is renamed (the old path gets a redirect to the new permalink).
