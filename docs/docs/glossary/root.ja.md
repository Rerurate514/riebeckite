# Root

Riebeckite が他のパスを解決する基準となるディレクトリで、Application root や content root があります。安定した root を基準に解決することで、パスをマシン間で持ち運べます。

## 役割

- パスを解決する安定した基準を与えます。
- Application と content の root を含みます。
