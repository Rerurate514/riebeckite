# Routable

URL で提供する entry を示す公開ビューで、unlisted の entry も含みます。ルーティングと出力生成は、discoverable ではなくこのビューを使います。

## 役割

- URL と出力を持つ entry を集めます。
- unlisted のページを直接 URL で閲覧できるように保ちます。
