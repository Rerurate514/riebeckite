# Series

順序を持ってまとまるコンテンツの集合で、frontmatter の series field で設定します。series の一覧は、同じ series 値を持つ content collection から作られます。

## 役割

- 関連するノートを順序付きの集合にまとめます。
- series field を対象にした collection から作られます。
