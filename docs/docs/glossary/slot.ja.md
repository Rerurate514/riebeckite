# Slot

ページレイアウトの中で Plugin が HTML を差し込める名前付きの位置です。レイアウトの slot はサイトが所有し、どこに描画するかを決めます。Plugin は slot 名に対して断片を渡すだけです。

## 役割

- Plugin がページレイアウトに HTML を差し込めるようにします。
- サイトが所有し配置を決め、Plugin は所有しません。
