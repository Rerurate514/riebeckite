# Slug

ノートの内部的な検索キーで、content index、manifest、content graph が使います。公開 URL ではないため、公開側では解決済みの公開位置から permalink を読みます。

## 役割

- ビルド中および実行時の query でノートを識別します。
- 公開 permalink とは切り離して管理します。
