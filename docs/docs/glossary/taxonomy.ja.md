# Taxonomy

/tags/ のような一覧ページへ、tag、folder、date でコンテンツをまとめる仕組みです。Taxonomy ページは content collection から作られ、リンクには permalink を使います。

## 役割

- コンテンツをたどれる軸で整理します。
- collection から一覧ページを生成します。
