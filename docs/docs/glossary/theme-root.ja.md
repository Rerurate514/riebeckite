# Theme Root

Theme が装飾し、token を適用する範囲の基準となるルート要素です。color mode と typography の data 属性をここに付けることで、カスケードがページ全体に届きます。

## 役割

- Theme の token と属性をページに適用します。
- color mode と typography の属性を保持します。
