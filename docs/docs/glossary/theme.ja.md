# Theme

CSS、design token、data 属性、カスケードを通してサイトの見た目を定義するパッケージです。Theme が担うのは見た目であり、サイトの構造、route、page type の ID、ページの構成ではありません。

## 役割

- コンテンツを変えずに見た目を制御します。
- コンポーネント向けの安定した styling hook を提供します。
