# Theme

A package that defines a site's appearance through CSS, design tokens, data attributes, and the cascade. A theme owns presentation, not the site structure, routes, page type IDs, or page composition.

## Role

- Controls how the site looks without changing content.
- Provides stable styling hooks for components.
