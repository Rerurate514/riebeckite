# Trace Span

Buildのobservabilityにおける名前付きの計測区間で、Pluginのhookやcacheの参照などの文脈のタグを持ちます。SpanはProfilerとobservabilityのイベントに使われます。

## 付く情報

計測のため区間に名前を付けます。Pluginやcacheなどの文脈tagを持ちます。
