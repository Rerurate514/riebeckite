# Trace Span

Build の observability における名前付きの計測区間で、Plugin の hook や cache の参照などの文脈の tag を持ちます。Span は profiler と observability のイベントに使われます。

## 役割

- 計測のため区間に名前を付けます。
- Plugin や cache などの文脈 tag を持ちます。
