# Translation

同じコンテンツの言語違いを結び付ける対応で、frontmatter で設定します。翻訳の対応があることで、リンクと graph が読み手の言語に従えます。

## 役割

- 1 つのノートの各言語版をまとめます。
- リンクを読み手の言語へ解決させます。
