# Typography

フォントの種類、サイズ、行間など、サイトの組版の設定です。Theme はページごとの上書きではなく、CSS と安定した hook を通して適用します。

## 役割

- フォント、サイズ、行間を制御します。
- Theme の CSS と安定した hook を通して適用します。
