# Unused Asset

どのコンテンツからも参照されていないassetです。診断は既定でオフになっており、有効にすると未使用のassetを報告します。

## 検出

`diagnostics`の設定で未使用のassetの報告を有効にします。削除候補のassetを、Buildを止めずに知らせます。
