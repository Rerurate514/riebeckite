# WikiLink

ノート同士をつなぎ、content graph に関係を作る `[[link]]` 記法です。Riebeckite は content index を通して解決し、解決できないリンクは diagnostic として残します。

## 役割

- ノート間に graph の辺を作ります。
- content index を通して名前、パスの後方一致、alias で解決します。
