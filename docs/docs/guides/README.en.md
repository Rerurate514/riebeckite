# Guides

Guides start from a task: "I want to publish an Obsidian vault", "I want a multilingual site", "I want to deploy automatically". If you are new, finish [Getting Started](../getting-started/README.en.md) first.

## By task

| I want to… | Guide |
| --- | --- |
| Write and organize articles | [Writing content](./writing-content.en.md) |
| Customize the site UI with HonoX | [Customizing your site](./customizing-your-site.en.md) |
| Build a homepage and browse routes | [Discovery recipes](./discovery-recipes.en.md) |
| Publish an Obsidian vault | [Obsidian](./obsidian.en.md) |
| Keep content and the site in separate repositories | [Content repositories](./content-repositories.en.md) |
| Build a multilingual site | [Localization](./localization.en.md) |
| Collect page views | [Analytics](./analytics.en.md) |
| Replace the icon, logo, or link preview image | [Branding your site](./branding.en.md) |
| Deploy | [Deployment](./deployment/README.en.md) |
| Upgrade Riebeckite or read migration notes | [Upgrading](./upgrading.en.md) |
