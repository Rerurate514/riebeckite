# AI 連携の境界

MCP はローカル情報の読み取りと変更内容の検証に加えて、公式 Plugin パッケージを公開 npm
レジストリから読み取り専用で検索できます。変更トークンを設定した場合だけ、変更 Plan の作成と
適用も行えますが、適用には人が CLI で Plan を承認する必要があります。MCP 自身は Plan を
承認できません。変更を適用する場合は、既存の CLI 手順で人が Plan を確認して承認します。

`ai setup --client` が書き込むクライアント設定はプロジェクト内に限定されます。
ほかのサーバーを保持し、既存の `riebeckite` エントリやグローバルのクライアント設定は
置き換えません。

Skills の同期も自動では行いません。更新前に内容を確認し、独自に編集した Skill は必要に
応じて退避してください。AI が MCP を使えない場合、Skills は CLI の検証へ戻ります。
