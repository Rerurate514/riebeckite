# Project guidance for AI

`RIEBECKITE_AI.md` records project-specific assumptions such as content location, frontmatter, links, and verification commands. Edit it as the project evolves.

Generated Skills cover sites, Plugins, Themes, configuration, troubleshooting, and upgrades. Each has `SKILL.md`, `references/guide.md`, and `assets/checklist.md`, and can be edited.

```sh
npm exec riebeckite skills sync
```

When a Skill version differs from the CLI, the command shows current and replacement content. Choose to review each Skill, replace all supported Skills, or skip the update.
