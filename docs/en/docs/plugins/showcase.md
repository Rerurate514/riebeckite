# Plugin Showcase

The Plugin catalog is available in [Plugins](./README.md). This page is the entry point for examples of what Riebeckite Plugins produce.

Individual Plugin pages contain source examples where the feature can be demonstrated safely in Markdown. Features that affect the whole page or site—such as search, table of contents, color mode, taxonomy pages, and the Garden Explorer—are documented on their own pages.
