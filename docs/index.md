# Riebeckite

Riebeckite publishes Markdown and Obsidian-style notes as a static site. Write in `content/`, add plugins for search, diagrams, and localization, choose a theme, and build a static site you can deploy anywhere.

New here? Start with **[Getting Started](./docs/getting-started/README.md)**. For every section in one place, see the [Documentation index](./docs/README.md).

Getting a first site running goes: **Quick Start → Installation → First Content → Presets → Deployment**.

## The shape of a first site

```text
my-site/
├─ content/              Markdown pages and assets
├─ app/                  Site UI generated by the preset
├─ riebeckite.config.ts  Site title, URL, theme, and plugins
└─ package.json          Local commands
```

A site author mainly edits `content/` and `riebeckite.config.ts`. Internal architecture is documented in [Framework](./docs/framework/README.ja.md).

For coding agents and automation, use the concise, rule-oriented [Agent documentation](./agents/README.md).
