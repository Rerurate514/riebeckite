# Localization

多言語コンテンツの公開、言語別 URL、言語切り替えなどを扱う Plugin です。

## 導入

```bash
npm install @riebeckite/plugin-l10n
```

Plugin の export 名や設定項目は、実装と package README を正本として確認してください。Riebeckite の Plugin は `riebeckite.config.ts` の `plugins` に登録して利用します。

## 使用例

同じ内容を複数言語で公開し、対応する翻訳ページ間を移動できるサイトで利用します。たとえば英語版と日本語版のDocsを `/en/...` と `/ja/...` で提供する構成です。

このページの記事ヘッダー付近にある Language の切替から、日本語版と英語版の同じページを行き来できます。

## 使いどころ

この Plugin が必要な場合だけ追加してください。Preset に含まれている場合は、同じ Plugin を重複して登録する必要はありません。

実際の表示例が用意されている場合は、[Plugin Showcase](./showcase.md) でも確認できます。
