# riebeckite-component checklist

- [ ] Inspect the route, existing components, Theme, and installed Plugins.
- [ ] Choose Plugin, Theme, or application ownership before adding code.
- [ ] Preserve public URLs, publication behavior, and route error states.
- [ ] Use semantic HTML with keyboard access and visible focus.
- [ ] Check narrow/wide layouts, color modes, and reduced motion when applicable.
- [ ] Add focused coverage for non-trivial behavior.
- [ ] Run `npm run check` and `npm run build`.
- [ ] Report ownership, affected routes, verification, and compatibility risk.
