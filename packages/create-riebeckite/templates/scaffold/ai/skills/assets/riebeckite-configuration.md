# riebeckite-configuration checklist

- [ ] Inspect configuration, scripts, content root, deployment, and active extensions.
- [ ] Change only the setting required and preserve unknown fields.
- [ ] Confirm root-relative paths and the external-content boundary.
- [ ] Keep secrets out of source and generated guidance.
- [ ] Run `npm run check` and `npm run build`.
- [ ] Inspect routes/output when publication behavior can change.
- [ ] Report effective settings, environment effects, rollback, and deployment risk.
