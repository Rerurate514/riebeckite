# riebeckite-plugin-catalog checklist

- [ ] Describe the requested capability and its build-time, browser, or server boundary.
- [ ] Inspect the current configuration and installed Plugins.
- [ ] Consult the official Plugin catalog, using MCP `riebeckite_plugin_catalog` when available, and read the selected Plugin reference.
- [ ] Compare the selected Plugin with the nearest alternatives and required companions.
- [ ] Add only the documented package, factory, and necessary options.
- [ ] Validate changed content with `npm run check` and `npm run build`.
- [ ] Inspect rendered or runtime behavior when the Plugin affects it.
- [ ] Report selection rationale, rejected alternatives, configuration, and migration risk.
