# riebeckite-plugin checklist

- [ ] Inspect the existing extension and its configured options.
- [ ] Select the narrowest Plugin API and validate external input.
- [ ] Declare processed-content dependencies accurately.
- [ ] Preserve `rb-*` contracts and expose only `rr-*` extensions.
- [ ] Add focused coverage for public behavior and invalid input.
- [ ] Run `npm exec riebeckite plugin verify <path> --level full`.
- [ ] Report API, cache behavior, verification, and compatibility risk.
