# riebeckite-site checklist

- [ ] Read the target and neighbouring content, configuration, and relevant links.
- [ ] Preserve frontmatter and Markdown conventions.
- [ ] Check aliases, inbound links, locale, and publication before a route-affecting change.
- [ ] Run `npm run check`.
- [ ] Run `npm run build` when routes, assets, embeds, or publication changed.
- [ ] Report changed files, validation, unresolved links, and publication risk.
