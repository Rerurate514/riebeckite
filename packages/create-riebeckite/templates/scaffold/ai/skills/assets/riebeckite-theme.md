# riebeckite-theme checklist

- [ ] Inspect the active Theme, site overrides, and representative pages.
- [ ] Keep the change presentational and use semantic tokens.
- [ ] Preserve `rb-*` hooks and use `rr-*` only for extensions.
- [ ] Test each changed component in light/dark modes and relevant states.
- [ ] Check mobile/desktop, focus, contrast, overflow, and reduced motion.
- [ ] Run `npm exec riebeckite theme preview <name>`.
- [ ] Report tokens/hooks, tested views, and visual risk.
