## Read for structure

Start with the outline. Check that each section earns its place and that the order carries the reader forward.

## Read it aloud

Rhythm problems only show up in the ear. Read the draft aloud and mark every sentence you stumble over, then rewrite those. Return to [[writing-a-useful-post]].
