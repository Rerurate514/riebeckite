# empty-no-utilities

A blank Riebeckite application shell — no theme, no plugins, no components, and no content. Everything is yours to add.

## Commands

```sh
npm install
npm exec riebeckite check
npm exec riebeckite dev
npm exec riebeckite build
```

npm is the reference package manager. pnpm 12 or newer works too; `pnpm-workspace.yaml` only affects pnpm.
