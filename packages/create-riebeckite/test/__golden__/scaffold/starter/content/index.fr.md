# starter

Bienvenue sur votre site Riebeckite.

Cette page provient de `content/index.md`. Ouvrez ce fichier, modifiez-le et enregistrez — le navigateur se met à jour pendant que vous écrivez.

## Éditer ce site
Le contenu vit dans `content/` en Markdown simple. Ajoutez un fichier, donnez-lui `publish: true` dans le frontmatter, et il apparaîtra dans le site construit.

Reliez les pages avec un WikiLink, par exemple `[[guide]]`.
