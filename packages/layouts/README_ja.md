# @riebeckite/layouts

Riebeckite サイト向けの組み合わせ可能な構造レイアウトプリミティブです。`@riebeckite/layouts/style.css` を読み込み、`SiteShell`、`SiteHeader`、`HeaderBrand`、`HeaderActions`、`ShellBody`、`ShellSidebar`、`ShellMain`、`ShellAside`、`ContentContainer`、`Drawer` を組み立てます。Layouts は配置とレスポンシブなレールを担当し、サイトやプラグインが内容を描画します。

[English](./README.md)

Drawer のフォーカス制御には `@riebeckite/layouts/client` を一度読み込みます。
