# Markmap Demo

The block below is written in the standard Markmap Markdown-heading notation.
The plugin emits it as a figure and the mindmap is drawn in the browser.

```markmap
# RIEBECKITE_EXTERNAL_MARKMAP_MARKER

## Notation

### Headings become nodes
### Nesting becomes the tree

## Rendering

### markmap-lib transforms the source
### markmap-view draws the SVG
```
