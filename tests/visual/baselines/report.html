Official theme visual baseline

Initial baseline — not a visual-regression comparison. Captured with Chrome 155 after rendering all ten official themes in explicit light and dark modes. The smoke fixture contains typography/markdown, code block, table, callout, navigation, TOC, and search. Each variant was also checked at 375px with no horizontal overflow; two representative mobile screenshots are included.

Visual regression remains pending an approved baseline and a subsequent comparison. This report records the reviewable source images, not a PASS for visual regression.
